# Design System: Neural Nexus

## Brand Vision
A sleek, futuristic, and professional "cyber-intelligence" aesthetic designed for high-density data synthesis and autonomous agent monitoring.

## 1. Color Palette

### Surface Colors
*   **Primary Surface:** `#131314` (Deep obsidian for main backgrounds)
*   **Surface Bright:** `#3a393a` (For elevated cards and containers)
*   **Surface Container Lowest:** `#0e0e0f` (For deep background layering)
*   **Surface Container Low:** `#1c1b1c` (Secondary sections)

### Brand & Accent Colors
*   **Primary Accent (Cyan):** `#00F0FF` (The "Neural" glow. Used for active states, key data points, and branding)
*   **Secondary Accent (Purple):** `#A855F7` (Used for "Action" buttons like Launching Agents or Transactions)
*   **Success/Stable:** `#22C55E`
*   **Warning/Risk:** `#F97316`
*   **Error/Critical:** `#EF4444`

## 2. Typography
*   **Font Family:** Inter (Sans-serif)
*   **Headings:** Bold, tracking-tighter, often uppercase for a technical feel.
*   **Body:** Medium weight, optimized for readability on dark backgrounds.
*   **Monospace:** Used for agent logs, terminal outputs, and system status indicators.

## 3. UI Components Style
*   **Corner Radius:** `8px` (Round Eight)
*   **Shadows:** Heavy use of glow effects (Cyan drop shadows) to simulate holographic or backlit interfaces.
*   **Glassmorphism:** `backdrop-blur` (10px - 20px) on top bars and sidebars with a `10-15%` white/border opacity.

## 4. Design Principles
*   **Information Density:** High. The layout should feel like a command center.
*   **Visual Proof:** Always show the work (logs, progress bars, status indicators).
*   **Hierarchical Glow:** The most important system statuses should have the strongest luminous accent.
